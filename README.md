# Taskora

**Take control of your time. Get things done.**

Taskora is a modern productivity and task management application designed to help you organize your daily activities, manage your schedule, stay focused, and improve your productivity.

Built with simplicity and usability in mind, Taskora brings essential productivity tools together in one place.

## ✨ Features

- **Task Management** – Create, organize, and manage your daily tasks.
- **Focus Mode** – Stay concentrated and dedicate time to important work.
- **Calendar** – Organize your schedule and keep track of your activities.
- **Productivity Tracking** – Monitor your progress and understand how you spend your time.
- **Modern UI** – A clean and intuitive interface designed for a better user experience.

## 🚀 Getting Started

Follow these steps to run Taskora locally.

### Prerequisites

- Flutter SDK
- Dart SDK
- Android device or emulator
- Visual Studio Code or Android Studio

### Installation

1. Clone the repository:
   git https://github.com/Mil-ko/Taskora
  
2. Navigate to the project directory:

   cd taskora

3. Install dependencies:

   flutter pub get

4. Run the application:

   flutter run
