# Taskora

**Take control of your time. Get things done.**

Taskora is a modern productivity and task management application designed to help you organize daily activities, manage your schedule, stay focused, and track your productivity — all in one place.

## ✨ Features

- **Task Management** – Create, organize, and manage daily tasks.
- **Focus Mode** – Stay concentrated with dedicated focus and break sessions.
- **Calendar** – Plan your schedule and keep track of activities.
- **Productivity Insights** – Monitor your progress and understand how you spend your time.
- **Modern UI** – A clean, intuitive, and user-friendly interface.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android device or emulator
- VS Code or Android Studio

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mil-ko/Taskora.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Taskora
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
